      What this version can and cannot do

      ✓ Optional OpenStreetMap road-direction diagnostics for your own travel; live rear-camera video; vehicle and traffic-light object detection; approximate object tracking; GPS speed/heading when available; audible experimental alerts; local event export.
      ⚠ Spoken traffic-light colors are estimates only. Multiple signals, glare, distance and lane assignment can cause errors. Never act solely on these announcements. ✗ It does not reliably interpret traffic rules, one-way restrictions, Google Maps navigation or reliable wrong-way violations.
